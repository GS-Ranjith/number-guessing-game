🎮 Number Guessing Game (Python)

A simple Python game where the computer selects a random number between 1 and 100, and the player has to guess it. After every guess, the game gives hints such as:

Too High

Too Low

Correct Guess

This project is perfect for beginners learning Python basics like loops, conditions, and random numbers.

📝 How it works

Computer picks a random number between 1 and 100

You guess until you get the correct number

Shows whether your guess is too high or too low

Counts total attempts

📌 Features

* Random number generation

* User input guessing

* Displays hints

* Counts attempts

* Simple and beginner-friendly
